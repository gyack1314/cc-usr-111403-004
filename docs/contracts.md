# 资料语义与接口边界

已有plan.py给scan/filter/project节点的不可变描述，含snapshot、schema、collation、visibility_scope及determinism；非确定函数节点不能共享。channels.py实现单订阅来源游标和每次pull/close事件，没有多读者广播。共享输出为有序页序列，每页有seq、digest、rows及末页标志；同一订阅者页不得遗漏或重交，完成只在其读完完整前缀后成立。公共表达式需要结构语义相同，不能仅按节点名或输出列名合并。晚加入可使用完整保留前缀或重启独立来源，策略须可解释。内存和临时盘容量分别配置；订阅者取消是独立事件，只有无剩余需求才能关闭共享生产者。来源错误使依赖者失败，消费者自身错误只取消自身分支。逻辑事件驱动，不以线程调度耗时判断公平。

plan.py只冻结表达式描述；channels.py每次open都创建独立游标，不含共享广播、订阅账和共享物化。

正文摘要绑定完整值，样例数据不限定输入规模；错误不等同空结果，接口使用中文错误说明。
